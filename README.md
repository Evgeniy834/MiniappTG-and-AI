[Название проекта] — это приложение, развёрнутое на платформе Telegram Mini App. В отличие от традиционных ботов с кнопками, оно предоставляет полноценный фронтенд-интерфейс внутри Telegram, позволяя пользователям без установки дополнительного приложения пользоваться возможностями AI.

Основная проблема, которую решает проект: [Например: снижает порог использования AI-инструментов, не требует от пользователей переключения между приложениями, использует нативную аутентификацию Telegram для быстрого входа].

🚀 Быстрый старт
Требования
Node.js 18+

Аккаунт Telegram (для создания тестового бота)

Локальный запуск
Клонирование репозитория:

bash
git clone https://github.com/Evgeniy834/MiniappTG-and-AI.git
cd MiniappTG-and-AI
Установка зависимостей:

bash
npm install
# или pnpm install
Настройка переменных окружения:

bash
cp .env.example .env
Заполните в .env:

TELEGRAM_BOT_TOKEN: получите у @BotFather

AI_API_KEY: ключ API вашего AI-сервиса

Запуск режима разработки:

bash
npm run dev
Предварительный просмотр в Telegram:
Используйте ngrok или localtunnel для проксирования локального порта в публичную сеть, затем настройте URL мини-приложения в @BotFather.

⚙️ Конфигурация
Переменная	Описание	Обязательна
TELEGRAM_BOT_TOKEN	Токен бота для проверки initData	Да
AI_API_KEY	API-ключ для вызова модели	Да
DATABASE_URL	Строка подключения к базе данных (если используется)	Нет
